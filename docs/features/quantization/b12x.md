# B12X Linear and Attention Backends

[B12X](https://pypi.org/project/b12x/) provides optional CUDA kernels for
NVIDIA SM120 and SM121 GPUs. Install the dependency with:

```bash
uv pip install "vllm[b12x]"
```

B12X linear kernels participate in automatic selection after established
optimized backends and before emulation. Select the linear and attention
backends explicitly with:

```bash
vllm serve <model> \
    --linear-backend b12x \
    --attention-backend B12X
```

The linear and attention backends can be selected independently.

## Supported Configurations

| Backend | Supported configurations |
| ------- | ------------------------ |
| Linear | Per-tensor FP8, 128x128 block FP8, MXFP8, NVFP4, and MXFP4 |
| Attention | Causal decoder MHA/MQA/GQA with BF16 model dtype; BF16 or FP8 E4M3 KV cache; head sizes 64, 128, 192, or 256; block size 64 or 128 |

The attention backend supports decode, prefill, mixed batches, speculative
verification, sliding-window attention, attention sinks, and CUDA graphs.

Dense W4A16 layers are not handled by B12X and continue to use another
compatible backend such as Marlin. The attention backend does not support MLA,
non-causal attention, ALiBi, logits soft capping, or context parallelism.
